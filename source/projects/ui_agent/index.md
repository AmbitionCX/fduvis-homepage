## 小组介绍

UI Agent小组以人机共生为长远愿景，主攻智能体系统（Agentic System） 研究，融合大模型算法、信息可视化与人机交互技术，构建集自主感知、决策、执行与迭代于一体的智能协作体系。研究聚焦UI智能体的多模态界面理解、任务规划与交互优化，攻克复杂交互场景下智能体可靠性、泛化性与可解释性等关键难题，推动人机交互从工具使用向深度协同共生演进。团队围绕真实应用场景开展多项核心课题研究：人机协同数据分析、基于用户行为感知的主动式UI智能体、Mobile UI Agent 自动化评测平台、数据资产智能管理系统等，致力于实现智能体技术与交互设计的深度融合与落地应用。
